# praktikum-data-science

# Praktikum Data Science

## Deskripsi  
Repositori ini berisi kumpulan notebook hasil praktikum Data Mining dan Machine Learning. Materi praktikum mencakup eksplorasi data, scraping data, text mining, regresi, klasifikasi, clustering, image processing, hingga prediksi time series. Seluruh notebook ditulis dalam bahasa Python menggunakan Jupyter Notebook.

---

## Daftar Praktikum

| No | Judul Praktikum | Deskripsi Singkat |
|----|------------------|--------------------|
| 1 | `Praktikum 1_Eksplorasi Data Sederhana.ipynb` | Analisis deskriptif awal terhadap dataset sederhana |
| 2 | `Praktikum 2_Data Noise, Manipulasi Data, Normalisasi Data.ipynb` | Pembersihan data, transformasi, dan normalisasi |

| 5 | `Praktikum 5 Text Mining.ipynb` & `Text Mining Latihan 2.ipynb` | Ekstraksi fitur dan analisis teks |

| 9 | `Praktikum 9_Clustering K-Means dan Agglomerative.ipynb` & `2.ipynb` | Segmentasi data menggunakan metode clustering |
